# The Last Ball at Blackthorne Manor

GitHub Pages package for the AP Literature archetype mystery game.

## Publish with GitHub Pages
1. Create or open a GitHub repository.
2. Upload the contents of this package to the repository root.
3. Commit the files.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the branch containing these files (usually `main`) and `/ (root)`.
7. Save and wait for GitHub Pages to publish the site.

`index.html` must remain at the repository root.

## Notes
- The game loads Three.js from public CDNs, so students need internet access for the 3D rooms.
- Embedded YouTube clips also require internet access and may be subject to school-network filtering.
- Student progress is saved locally in the browser/device they use.
